CHAPTER#1: Meet Your OpenCode

# 什么是OpenCode
OpenCode 是一个免费开源项目，是一个在终端里运行的 AI 编程助手，与几乎所有主流大模型都可以搭配使用。

你可以用它进行Vibe Coding，你说一句话，它帮你：分析需求、修改代码、执行命令、自动完成多步任务。

不懂编程的普通人也可以用OpenCode写代码、做App、协助办公，以及更多无限可能。

它被称为Claude Code的高性价比平替。对于国内用户，在Anthropic 反花+封号+需要海外信用卡等缺点的情况下，OpenCode确实是一个不错的选择。

# 安装OpenCode
网络上安装教程非常多，不重复造车轮了
记得安装前置软件，如Node.js，python，Git等

Windows常见安装方式：
进入管理员权限的powershell
输入 npm install -g opencode-ai

# 使用OpenCode的方式
1. 最常用就是在cmd终端/powershell里直接使用，稳定，但是对于编程新手需要适应终端界面和指令操作（但其实也没那么难）。
2. 使用VS Code或者Cursor等IDE。先安装OpenCode，再在VS Code里安装OpenCode插件。好处是可以适配程序员编程习惯、实时看到文件资源器、可视化github管理。
3. Warp这种第三方终端。界面简单，有指令记忆功能，可以看到文件资源器。但是经常卡死，不推荐。

#启动 OpenCode 并进入项目
在PowerShell里输入
cd ~/your-project  # 需要整个换成项目的绝对路径
opencode

#CLI常用指令
这里的CLI指令用于没有进入OpenCode之前，在终端界面里使用

以opencode开头，加上下面后缀
标志	简写	描述
--continue	-c	继续上一个会话
--session	-s	后面加要继续的会话 ID
--fork		继续时分叉会话（与 --continue 或 --session 配合使用）

列出所有可用的代理：opencode agent list
为任何想要使用的提供商配置 API 密钥：opencode auth login
（密钥存储在 ~/.local/share/opencode/auth.json 中。）
列出凭据文件中存储的所有已认证提供商：opencode auth list
从凭据文件中清除提供商信息以完成登出：opencode auth logout
列出已配置提供商的所有可用模型：opencode models [provider]
刷新模型缓存： opencode models --refresh
列出所有 OpenCode 会话：opencode session list (按q退出）
列出所有 OpenCode 会话：opencode session list -n [number]
更新到最新版本：opencode upgrade
更新到指定版本：opencode upgrade v0.1.48
查看版本号：opencode -v
（[]不需要输入，只是表示该内容是optional）

常看常新：https://opencode.ai/docs/zh-cn/cli/

## 用 @ 引用文件
这是 OpenCode 最强大的功能——让 AI 直接读取你的文件。
注意，输入 @ 后会看到 Agent 列表（如 @explore）和文件夹。继续输入文件名的部分内容（如 @pack），才会搜索并显示匹配的具体文件，用方向键选择后按 Enter 确认。

## 额外说明
grep 和 glob 都最多返回 100 条结果。如果结果被截断，可以：
缩小搜索目录（"只在 src 目录下搜索"）
用更精确的关键词
过滤文件类型（"只搜索 .ts 文件"）

你不需要手动调用这些工具。你只管用自然语言描述需求，AI 会自动选择合适的工具。

## 聪明的edit工具
为什么 edit 是 OpenCode 最聪明的工具。它不是简单地"改第几行"，而是用字符串匹配来精确定位要修改的位置。

edit 工具有 9 层匹配策略，从严格到宽松逐层尝试：

策略	说明	例子
精确匹配	完全一致	foo 匹配 foo
行首尾空白忽略	忽略每行开头结尾的空格	foo 匹配 foo
首尾行锚点	用第一行和最后一行定位代码块	函数开头和结尾匹配
空白规范化	多个空格当一个	a b 匹配 a b
缩进容错	忽略整体缩进差异	2 空格缩进匹配 4 空格
转义字符处理	处理 \n、\t 等	a\nb 匹配实际换行
边界修剪	去掉首尾空白后匹配	前后有空行也能匹配
上下文感知	用首尾行 + 中间内容相似度	代码块略有变化也能匹配
多处匹配	找到所有精确匹配	配合 replaceAll 使用

简单说：你给 AI 的代码片段不需要和文件里的完全一致，有点缩进差异、空格差异都没关系。

如果 oldString 在文件中出现了多次，edit 会报错：
Found multiple matches for oldString.
Provide more surrounding lines in oldString to identify the correct match.

解决方法：
让 AI 提供更多上下文（多包含几行代码），确保唯一匹配
或者用 replaceAll 参数一次性替换所有匹配


# 高级功能
## Fork 会话
为什么需要？
有时候你想从对话的某个节点"分叉"出去，尝试不同的方向，但又不想丢掉原来的对话。Fork 就是干这个的。

Fork 会复制当前会话的所有历史消息，创建一个新会话。新会话的标题会加上 (fork #1) 后缀，再次 Fork 则递增为 (fork #2)、(fork #3)……

操作方式：
在终端界面使用CLI指令 opencode -c --fork可以给最近的一个会话进行分叉操作

在TUI里，Fork 没有默认快捷键，你可以在tui.json 中给它绑一个：
{
  "keybinds": {
    "session_fork": "<leader>f"
  }
}
配置后，按 Ctrl+X f 就能 Fork 当前会话。
你应该看到：新会话出现，标题类似 原标题 (fork #1)
